# ساحة التدريب الحقيقية — STAR Cyber Range

أهداف ضعيفة عمداً تعمل في Docker على جهاز Kali، وتهاجمها بأدواتك الحقيقية. هذه أول خطوة في المحور الثاني من خطة التطوير، والأساس الذي سيبني عليه STAR Coach وSTAR Agent لاحقاً.

## الأهداف المتوفرة

| الهدف | الرابط المحلي | المحتوى | أعلام ديناميكية |
|---|---|---|---|
| OWASP Juice Shop | http://127.0.0.1:3000 | أكثر من 100 تحدٍّ ويب حديث | ✅ |
| DVWA | http://127.0.0.1:4280 | تطبيق PHP كلاسيكي بمستويات صعوبة (الدخول: admin / password) | — |
| OWASP WebGoat | http://127.0.0.1:8081/WebGoat | دروس موجّهة خطوة بخطوة | — |

## كيف تعمل العزلة

```
Kali (جهازك) ──127.0.0.1:3000/4280/8081──▶ gateway (nginx)
                                              │  شبكة range_internal (internal: true)
                                              ├── juice-shop
                                              ├── dvwa
                                              └── webgoat      ✗ لا طريق إلى الإنترنت أو شبكتك المنزلية
```

- الأهداف موجودة **فقط** على شبكة Docker من نوع `internal`، ولا يوجد لها أي طريق للخروج.
- البوابة تنشر المنافذ على `127.0.0.1` فقط، فلا يصل إليها أي جهاز آخر في شبكتك.
- كل تشغيل أو إعادة ضبط **ينشئ الحاوية من الصفر**، فلا تبقى أي حالة من المحاولة السابقة.
- لا تغيّر `127.0.0.1` إلى `0.0.0.0`، ولا تربط هدفاً بشبكة `range_edge`.

## التشغيل لأول مرة

```bash
# 1) Docker و Compose
sudo apt install -y docker.io docker-compose-plugin
sudo usermod -aG docker "$USER"   # ثم سجّل خروجاً ودخولاً

# 2) الرموز المحلية (مرة واحدة)
bash scripts/init-local.sh

# 3) فعّل الساحة
echo 'STAR_RANGE_ENABLED=true' >> .env.local

# 4) شغّل الـ API والواجهة
cd services/api && set -a && source ../../.env.local && set +a
uvicorn app.main:app --host 127.0.0.1 --port 8000
# في طرفية ثانية:
cd apps/web && npm run dev
```

افتح `http://127.0.0.1:5173/#operations`، والصق رمز المشغّل، ثم اختر تبويب **ساحة التدريب**.

> **ملاحظة:** إضافة مستخدمك إلى مجموعة `docker` تعطيه صلاحيات تعادل root على الجهاز. هذا مقبول على جهاز تدريب شخصي، لكن انتبه لذلك.

## دورة المحاولة

1. **تشغيل:** يحتاج رمز الموافقة المستقل وسبباً وتأكيد النطاق. أول تشغيل ينزّل الصورة وقد يأخذ دقائق.
2. **الهجوم:** من أدوات Kali على `127.0.0.1`. ولتسجيل جلستك:
   ```bash
   bash scripts/range-shell.sh juice-shop
   ```
   تُحفظ كل الأوامر والمخرجات في `~/.local/share/kali-osint-star/sessions/` بصلاحيات 700. وتعيد تشغيلها بـ `scriptreplay`.
3. **تسليم العلم (Juice Shop):** عند حل تحدٍّ يظهر رمز من 40 حرفاً في الإشعار. أدخله مع اسم التحدي كما في Score Board. الخادم يتحقق منه بمفتاح المحاولة الحالية فقط.
4. **إعادة ضبط:** محاولة جديدة بمفتاح جديد. الأعلام القديمة لم تعد صالحة.
5. **إيقاف وحذف:** يحذف الحاوية ويغلق المحاولة.

## الأعلام الديناميكية

- عند كل تشغيل يولّد الـ API مفتاحاً عشوائياً من 256 بت، ويمرّره إلى Juice Shop كمتغير بيئة `CTF_KEY`. المفتاح لا يظهر في سطر الأوامر ولا في أي رد من الـ API.
- العلم = `HMAC-SHA1(CTF_KEY, اسم التحدي)`، وهي نفس طريقة Juice Shop.
- لذلك العلم يثبت أنك حللت التحدي **في هذه المحاولة**: لا ينفع نسخه من الإنترنت أو من محاولة سابقة.
- عند انتهاء المحاولة يُحذف المفتاح من قاعدة البيانات.

## الأمان في الـ API

- كل المسارات تحتاج `STAR_OPERATOR_TOKEN`، والتشغيل وإعادة الضبط تحتاج أيضاً `STAR_APPROVAL_TOKEN`.
- الساحة **معطّلة افتراضياً** حتى تضع `STAR_RANGE_ENABLED=true`.
- أوامر Docker قائمة وسائط ثابتة (`argv`) بدون shell. الجزء المتغير الوحيد هو اسم هدف من قائمة مكتوبة في الكود.
- البيئة المرسلة إلى Docker لا تحتوي رموز المشغّل أو الموافقة.
- كل عملية مسجّلة في سجل التدقيق.

## القادم

- **GOAD (Active Directory):** يحتاج أجهزة Windows افتراضية، فيعمل على VirtualBox أو Proxmox وليس Docker. سيحوّل W02–W04 إلى تمارين حقيقية.
- **Vulhub:** إضافة ثغرات CVE محددة كأهداف.
- **STAR Coach:** يقرأ سجلات الجلسات والأعلام المحلولة ليقترح التمرين التالي.
