# نطاق الاختبارات المصرح بها
- اختبر فقط الآلات أو مختبرات HTB وTryHackMe وPortSwigger Academy وغيرها عندما تخصص لك المنصة هدفاً واضحاً وفق شروطها.
- صفحات المنصات وخوادمها الرئيسية **ليست أهدافاً مصرحاً بها**.
- قبل أي اختبار سجل المالك، النطاق، الوقت، التفويض، والقيود.
- الواجهة الحالية تحفظ بيانات التقدم محلياً ولا ترسل طلبات فحص لأهداف مسجلة.
- أي Kali Agent مستقبلي يتطلب مصادقة، صلاحيات دقيقة، قائمة سماح، موافقات، سجلات تدقيق وعزل شبكة.
