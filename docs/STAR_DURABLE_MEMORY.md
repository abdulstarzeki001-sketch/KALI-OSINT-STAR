# STAR Memory
D1 binding STAR_MEMORY, schema cloudflare/memory/001.sql. Access JWT verified per request, owner key derived from verified identity, all queries scoped. No automatic execution or model-generated writes. Opt-in chat archive and retrieval in #agent. Current retrieval prioritizes instructions, pending tasks and notes, bounded to 2800 characters plus framing. Chat archives are browsable and manually reusable, not automatically loaded into every prompt. 50 per page, 2000 chars per note/task/instruction and 60000 per chat record; replies exceeding limit surface an error. No old local chat migration, no Minis or agent-runtime memory integration yet. Cloud archive and local deletion separate. Task completion manual, not evidence of execution. No guarantees against data loss; back up D1 and avoid secrets. Production requires D1 binding and authenticated smoke test.
