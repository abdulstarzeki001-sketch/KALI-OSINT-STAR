# STAR AI Agent — دليل المحادثة السحابية

## الصفحة

الرابط المباشر بعد نشر تطبيق Pages: `https://kali-osint-star.pages.dev/#agent`

هذه صفحة React منفصلة عن `#ai` القديمة لتحليل التقارير. تعمل على Safari في الآيفون والآيباد وعلى متصفح الحاسوب، وتُحمّل عند فتحها فقط لتقليل تكلفة تحميل لوحة التحكم.

## مميزات فعلية

- أربع شخصيات عمل: محادثة عامة، برمجة، تحليل سيبراني، وAI Agent لتقسيم المهام.
- محادثة متعددة الأدوار مع الرد المتدرج عبر `text/event-stream`.
- أكثر من جلسة، حذف الجلسات، اختيار الجلسة، وتنزيل Markdown.
- حفظ مؤقت داخل `sessionStorage` افتراضياً. التخزين الدائم على الجهاز (`localStorage`) **اختياري** ويُفعّل فقط بإذن المستخدم.
- إعداد درجة الإبداع، مرفق نصي مقتطف (لا يُرفع الملف نفسه، بل النص المقروء فقط)، عرض Markdown بعزل HTML ضار وروابط آمنة.
- لوحة منفصلة لفحص وجود أدوات Railway ونتيجة التنفيذ الثابت عبر `/api/terminal/tools/assistant` **بعد الضغط على زر الفحص**.

## الاتصال الحقيقي

```text
iPhone/iPad Safari
  -> Cloudflare Access (المالك المسجل)
  -> Pages Function /api/ai/chat
  -> VerifyAccessRequest JWT + origin + hostname
  -> STAR_AI Service Binding (private)
  -> kali-osint-star-ai-core Worker /chat
  -> Cloudflare Workers AI Llama 3.3 70B
  -> SSE response -> chat view
```

لا تُنشر مفاتيح API في Vite أو المتصفح. لا يوجد proxy عام غير محمي. الطلبات ذات الحالات الخاطئة لا تصل إلى الاستدلال. مرفقات النص وسجل المحادثة تُرسَل إلى النموذج المختار داخل سياق الاستدلال فقط، ولا تُحفظ في قاعدة بيانات من هذا التطبيق.

**مهم:** عبارة «بدون قيود» تعني هنا عدم قصر المساعد على قوالب تحليل دفاعي أو ردود محلية تجريبية؛ لا تعني إزالة ضوابط المزوّد، أو حصة النموذج، أو السماح لأوامر Shell وC2 بتنفيذ تلقائي من الدردشة. يحق للمستخدم كتابة الأسئلة العامة والتقنية والبرمجية بحرية، ويتولى مزوّد النموذج معالجة المحتوى بحسب سياسته.

## خيارات الخصوصية

المحادثات في ذاكرة الجلسة الافتراضية فقط؛ عند اختيار حفظ المحادثات على هذا الجهاز تُكتب محلياً في localStorage وغير مشفرة. **لا تفعّل هذا الخيار على جهاز مشترك**. لا تشارك أسراراً أو كلمات مرور أو تقارير حكومية غير مصرّح لها في المحادثة.

لا يُكتب محتوى المحادثات في مستودع GitHub أو Cloudflare Logs بواسطة شيفرة الصفحة. ويبقى إرسال النص إلى مزود الذكاء ضرورياً للرد.

## حدود التشغيل الفعلية

- النموذج مربوط بخدمة Cloudflare: لا يعني وجود الواجهة وحده أن الحصة متاحة؛ يجب أن يتم إرسال رسالة والرد عليها من جلسة مالك مصادق عليها.
- إذا عاد HTTP 503 فالمحرّك أو الحصة غير متاحين، ولن تُعرض إجابة اصطناعية.
- وضع Agent ينشئ خطة وتوصيات، لكنه لا يضغط أزراراً أو ينفذ أوامر ترمنال ذاتياً.
- تنفيذ جرد أدوات Railway مسار منفصل مصرح به. لا يتم تمرير نص المحادثة إلى Shell أو إلى أدوات الاختراق.
- حد الرسائل 24 رسالة في الطلب، حد النص 5,000 حرف لكل رسالة و24,000 حرف لمجموع السياق. الأقدم قد يستبعد عند تجاوز الميزانية.

## نشر الإصدار

1. اختبر `npm run test:cloudflare`, `npm run test:ai-core`, `npm run typecheck`, `npm run build`.
2. انشر محتوى `cloudflare/ai-core/worker.mjs` على Worker `kali-osint-star-ai-core` مع إبقاء AI Binding باسم `AI` وإيقاف نطاق `workers.dev`.
3. انشر Pages React/Vite بعد دمج PR واستكمال CI.
4. من **جلسة مالك عبر Cloudflare Access** افتح `/#agent`، أرسل سؤالاً، وتحقق من استلام SSE. النجاح في اختبارات CI ليس إثبات اختبار جلسة المالك عبر Safari.

للتراجع: أعد إصدار Worker السابق أو استرجع التغييرات من GitHub، وتأكد من بقاء `/analyze` القديم متوافقاً.
