# STAR Agent Runner — خدمة تنفيذ فعلية ضمن Railway

هذه خدمة جديدة مستقلة عن STAR-ShellFish وعن STAR-AI-Cyber-Gateway. تمتاز بمساحة عمل معزولة، ومهام قابلة للمتابعة، وخطوات تنفيذ حقيقية، وعرض طلبات الموافقة قبل تعديل الملفات أو تشغيل اختبار.

## نموذج الاستدلال
- STAR_MODEL_BACKEND=cloudflare: يستعمل النموذج الخاص بمشروعك في Cloudflare بواسطة صفحة \`/api/agent/inference\` المحمية بجلسة Cloudflare Access JWT.
- لا يُلصق مفتاح API في المتصفح ولا في المصدر.
- النموذج الحالي نصي؛ نطلب منه إجراءً واحداً بتنسيق JSON وتتحقق الشيفرة من قائمة الأدوات. **هذا ليس دعماً أصلياً مضموناً لـfunction calling**؛ قد يرد النموذج نصياً أو لا يلتزم بالتنسيق. حينئذ تنتهي المهمة دون تنفيذ أدوات.
- يجب اختبار وصول Railway إلى واجهة Cloudflare من جلسة مصرح بها؛ نجاح health وCI لا يثبت نجاح الاستدلال الفعلي.

## واجهة النظام
\`https://kali-osint-star.pages.dev/#runtime\` هي الواجهة المستهدفة. يرسل Cloudflare Pages JWT من Access إلى خادم Railway على عنوان محدد بالاسم. يحقق خادم Python التوقيع RS256 ومصدر JWT والـAudience والوقت ونوع app بشكل مستقل.

## حدود العزل
- مساحة العمل \`/workspace\` تضم **نسخة كود من المستودع داخل الحاوية** وليست مجلد الكمبيوتر الحقيقي أو مستودع GitHub على الإنترنت.
- أدوات قراءة الملفات والبحث وgit status تعمل في المساحة المسموح بها، مع قواعد منع ملفات الاعتماد والروابط الرمزية.
- التعديل والاختبارات تحتاج موافقة، وحتى بعد الموافقة أوامر الاختبار محصورة بأوامر محددة في الشيفرة، بلا Shell غير مقيد.
- لا ينفذ git push أو اختبارات اختراق أو مسح مواقع تلقائياً.
- الحد الأقصى الحالي في Railway **1 GB RAM**: صورة خفيفة، ولذلك لا يوجد Chromium في خدمة الإنتاج ولا تُفعل صلاحيات المتصفح. متصفح Playwright موصوف في صورة Docker الكاملة لاستخدام VPS أوسع فقط.
- الذاكرة والملفات المحلية داخل الحاوية قد تضيع عند إعادة النشر ما لم يُوصل Volume منفصل. لا تستخدمها كخزن دائم قبل تهيئة المجلد الدائم.

## اختبار القبول
- تسليم مهمة «اقرأ README.md ثم لخص الهدف» ينبغي أن يظهر محتوى مأخوذاً من أداة read_file، لا نصاً مختلقاً، **إذا كان النموذج متاحاً وقادراً على JSON**.
- تسليم مهمة لتعديل ملف ينبغي أن يقف على حالة approval_required، وألا يتغير الملف قبل الموافقة.
- من جلسة غير مصرح بها يجب أن يرجع 401 دون تشغيل نموذج أو أدوات.
- لا تعتبر المشروع ناجحاً بالكامل حتى تنفذ تجربة مباشرة من واجهة حساب المالك وتشاهد سجل الأدوات ونتائجها.

تم تخصيص Access app منفصل للاستدلال مع سياسة Linked App Token تقبل فقط JWT من تطبيق KALI OSINT STAR Owner Only. المسار الفرعي له AUD منفصل؛ هذه الخدمة لا تقبل JWT تطبيق الموقع الأصلي مباشرة.
